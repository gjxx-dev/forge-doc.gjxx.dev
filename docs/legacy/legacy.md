# 旧版本文档

Forge 已存在多年，你仍然可以方便地访问针对早至 Minecraft 1.1 的 Forge 构建。各版本之间存在显著差异，支持如此多不同的版本几乎是不可能的。因此，Forge 使用 LTS（长期支持）机制，将以前的某个主版本视为 LTS。只有最新版本和当前的 LTS 版本会在侧边栏的版本下拉中拥有便捷可访问的文档。不过，一些旧版本曾经是 LTS 或曾为当时的最新版，因此曾撰写过文档。可在此处找到指向这些旧站点的链接以供参考。

!!! important
    这些旧版本文档仅供参考。请不要在 Forge Discord 或 Forge 论坛上请求对旧版本的技术支持。**当你使用旧版时，你不会获得支持。**

### RetroGradle

**RetroGradle** 是一个归档计划，旨在将旧的 ForgeGradle 1.x 到 2.3 的工具链以及其对应的 Minecraft 版本迁移到现代的 ForgeGradle 4.x 及以上工具链。目标是通过采用可验证的现代工具链（基于数据而非特定版本的硬编码流程）来保留所有已发布过的 Minecraft Forge 旧版本。

如果有开发者愿意参与该归档工作，请加入 The Forge Project 的 Discord 服务器并询问指定频道的指引。请注意，该计划旨在**保存**这些旧版本以供社区参考，而**不**旨在支持为这些已不受支持的旧版本开发模组。对于使用或为不受支持的旧版本开发，将不会提供支持。
