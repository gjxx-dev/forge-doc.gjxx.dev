# 网络（Networking）

客户端与服务端之间的通信是成功模组实现的核心。

网络通信主要有两个目标：

1. 确保客户端视图与服务端一致（例如：坐标 (X, Y, Z) 的花朵已经生长）。
2. 提供客户端告知服务端玩家行为变化的方法（例如：玩家按下某个按键）。

最常见的实现方法是在客户端与服务端之间传递消息，这些消息通常是结构化的，包含便于发送与解析的数据。

Forge 在 [netty][] 之上提供了多种简化通信的技术。

对新模组来说，最简单的是使用 [SimpleImpl][channel]，它将 netty 的大部分复杂性抽象掉，采用消息与处理器的方式。

[netty]: https://netty.io "Netty Website"
[channel]: ./simpleimpl.md "SimpleImpl 详解"
