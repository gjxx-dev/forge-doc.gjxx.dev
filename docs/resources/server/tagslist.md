# Tags 列表

Forge 打包了许多对模组有用的标签（tags），既包括 Forge 特有的标签，也包括在多个 loader 间成为事实标准的通用标签。可在 `net.minecraftforge.common.Tags` 类中找到这些标签。本页列出了这些标签及其内容。

!!! note
    本页不包含 Vanilla 标签。有关 Vanilla 的标签请参阅 `net.minecraft.tags` 包。

此页由 [CommonTagsDumper][commontagsdumper] 生成，截至 Forge 52.0.20。注意并非所有 Forge 构建都会包含标签变更，因此本页引用较旧构建并不意味着过时。你应将 Forge GitHub 上生成的 JSON（见下文）视为事实来源。本页仅为便捷参考，不保证实时更新。
